# TLS Test program
This directory contains a TLS test program for both original TLS and TLS with remote attestation.
 - The original TLS program
    The server certificate, server.{crt,csr,key}, is used
 - TLS with remote attestation
    The server/client certificates are dynamically created. This sample program does not add any evidence into the certificate.

1. Building OpenSSL
   ```sh
   pushd $HOME/work/src
   git clone https://github.com/openssl/openssl.git
   cd openssl
   OPENSSL_SRC=`pwd`
   OPENSSL=$HOME/tools/ssl
   ./Configure --prefix=$OPENSSL
   make -j8
   make install
   popd
   ```

2. Building tltest<br>
Make sure that shell environment variables, OPENSSL and OPENSSL_SRC, are defined.
   ```sh
   $ make
   ```

3. Testing the original TLS<br>
For testing the original TLS library, the server certificate is needed.
In this example, this cerfificate is signed by a self-signed CA.
   1. Creating self-signed CA for testing
      ```sh
      $ make oreore
      ```
      - The following files have been created under the ./CA directory
        - my_ca.key
        - my_ca.crt
        - my_ca.srl and two hash-based symbolic links generated by the c_rehash command

   2. Run a test program using two windows, server-side and client-side, as follows:
      1. Server-side
         ```sh
          $ make run-tlsserver
         ```

      2. Client-side
         ```sh
          $ make run-tlsclient
         ```

4. Testing TLS with remote attestation<br>
   1. Run a test program using two windows, server-side and client-side, as follows:
      1. Server-side
         ```sh
          $ make run-tlsra-server
         ```

      2. Client-side
         ```sh
          $ make run-tlsra-client
         ```
